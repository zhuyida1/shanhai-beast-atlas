二、公共页面骨架

多数页面采用统一头部、主体内容、页脚结构。栏目页和详情页在主体部分根据功能不同分化。

公共头部 Header

  • 1 Logo / 品牌：山海异兽录
  • 2 主导航：首页、神兽图鉴、栖息地、文化延伸、关于我们

主体 Main

  • 首页 轮播主视觉、统计、列表、精选卡片
  • 栏目页 banner、面包屑、筛选/侧栏、列表
  • 详情页 hero、侧栏、正文卡、相关推荐

公共页脚 Footer

  • 导航 首页、神兽图鉴、栖息地
  • 详情 神兽详情、地域详情、文化详情
  • 说明 文化延伸、原典摘读、关于我们、资料来源

三、页面内容结构拆解

下面按页面类型列出主要版块，方便后续修改时快速定位。

首页 index.html

  • 首页主题轮播：九尾狐、凤凰、饕餮三张 hero slide。
  • 黑金统计条：神兽收录、典籍出处、地域场景、文化典故。
  • 两栏内容列表：山海原典摘读、文化典故速览。
  • 神兽精选卡片：饕餮、白泽、凤凰、麒麟、玄武。
  • 红色标语带和统一黑色页脚。
入口页轮播内容聚合

神兽图鉴 beasts.html

  • 栏目 banner + 面包屑导航。
  • 顶部筛选 chips：全部、瑞兽、凶兽、羽族、鳞甲、山兽、水兽。
  • 侧边栏分类说明，满足栏目页分类导航需求。
  • 图鉴卡片网格和分页脚本，当前展示 16 个结果。
  • 重点导向六个独立神兽详情页。
二级栏目侧栏筛选搜索

栖息地地图 map.html

  • 考据增强版 hero，明确“路线图思路、非现代经纬度”。
  • 研究说明条：路线优先、证据分级、经篇分层、交互保留。
  • 左侧筛选面板：经篇/图层、神兽属性、显示控制、图例。
  • 中间 SVG 交互地图，右侧文献点位详情卡。
  • 点位列表和考据说明区域由 data/map-points-rigorous.js 与 js/map-rigorous.js 支撑。
二级栏目交互地图数据脚本

文化延伸 culture.html

  • 文化专题 banner + 说明卡。
  • 四项 feature strip：原典摘读、图像再设计、地图联动、文创转译。
  • 侧边栏分类：神兽典故、地域神话、祭祀纹样、后世演绎。
  • 专题文章列表，重点入口为 classics.html 与 culture-detail.html。
  • 下方分栏：地域神话、视觉转译。
二级栏目专题文章文化线索

神兽详情组 beast-*.html

  • 包含九尾狐、白泽、凤凰、麒麟、饕餮、玄武六个详情页。
  • 统一结构：hero → container → sidebar → main-card → 正文 section → 相关推荐 → slogan。
  • 正文重点包含：神兽本源、核心特征、形态特征、能力特性、栖息之地、象征寓意、文化延伸。
  • 每页通过相关神兽推荐回链到其他详情页或图鉴体系。
详情页统一模板相关推荐

文章与列表组 classics / culture / habitat

  • classics.html：原典摘读列表页，按南山经、西山经、北山经、海荒经分组编排原典条目，顶部提供关键词检字与经篇印签筛选；条目标题含经篇标签、一句话摘要与配图位，链接指向 article.html?id=N。
  • article.html?id=N：原典摘读条目页，正文由 data/articles.js 按 id 渲染。结构为题签（兽名、注音、图版占位）→ 经文对读（左侧原文纸签与注释，右侧白话，可切换对读／只读原文／只读白话）→ 名物考四格 → 义疏 → 相关条目 → 上一条／目录／下一条，顶部有阅读进度线。
  • culture-detail.html：青丘九尾文化详解，展开原文解读、历代解读、双重身份、民俗表现。
  • habitat-detail.html：南山青丘地域详情，连接九尾狐、凤凰、旋龟、蛊雕等地域内容。
  • 共同结构：sub-hero、面包屑、侧栏导航、文章正文、相关页面推荐。
