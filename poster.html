📖项目简介

《山海异兽录》是一个以《山海经》神兽插图科普为核心的国风科普网站。作品围绕"神兽图鉴—栖息地地图—文化典故"三主线展开，通过国风视觉设计，让用户在浏览神兽图像、分类探索和信息层级递进中理解中国上古神话内容。

🎯设计目标

  • 打造图文并茂、视觉统一的国风神兽科普站点
  • 实现三层页面结构（首页→栏目→详情），信息层次分明
  • 神兽图鉴支持分类筛选与关键词搜索
  • 栖息地页以现代地图重构《山海经》地理叙事
  • 文化延伸页展示原文出处、历代解读与民俗演变

⚙️技术架构

  • 前端技术：HTML5 + CSS3 + JavaScript（纯静态）
  • 页面数量：8 个完整 HTML 页面
  • CSS 体系：国风视觉变量系统，支持响应式布局
  • 交互功能：神兽分类筛选、关键词搜索、客户端分页、轮播图、平滑滚动
  • 兼容性：桌面端 1400px + 移动端 390px 双端适配
  • 特色技术：CSS Grid/Flexbox 布局、backdrop-filter 毛玻璃、CSS 渐变与纹理叠加
