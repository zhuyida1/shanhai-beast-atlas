# 栖息地板块实现与验收记录

完成日期：2026-10-19。

## 页面入口与使用

- [山海舆图](../map.html)：全图默认选择九尾狐；支持经篇、类型、资料状态与关键词组合筛选。
- [地域手札](../habitat-detail.html)：无参数时显示青丘；从地图进入时显示真实地点及其关联异兽。
- 本机预览为 `http://127.0.0.1:8126/map.html`，仅在本机静态预览服务运行时可用。关闭服务后仍可直接双击 `map.html` 或从 `index.html` 进入；不需要安装依赖或构建。
- 桌面使用拖动、滚轮和缩放按钮。手机默认允许页面滑动；点击“操作地图”后可单指拖动、双指缩放，点击“完成操作”后恢复页面滑动。触屏平板同样提供该入口。
- 地图、名录和异兽手札联动。邽山的蠃鱼与穷奇共用一个地点；地点密集时显示数量簇，点击后可放大或逐个选择。
- 详情入口携带经篇、类型、资料状态、搜索词、地名和路线开关、选中记录、相机参数，返回时恢复这些状态。
