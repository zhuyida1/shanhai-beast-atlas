# 全站优化记录 · 2026-10-23

本轮按用户要求优化现有整站，延续山海画卷的插画、书法标题、青灰背景与朱砂金色。没有替换文献内容、改变地图坐标或引入外部服务。

## 资源加载

将三张首页/栏目主视觉和一张全站共用山水图转换为 WebP，保持像素尺寸，保留原 PNG 文件。四张素材合计从 14,272,855 字节降至 1,661,322 字节，约减少 88.4%；这是素材文件体积变化，不是实测页面加载时间。

更新 HTML 图片、视频封面、预加载地址和 CSS 背景引用。共用脚本补充图片异步解码；首页在浏览器明确开启节省流量或报告 2G 连接时，默认显示静态画面，用户仍可主动播放。

## 图鉴与检字

- 图鉴搜索、分类及页码同步到网址，刷新保留；`/` 聚焦搜索，Esc 清除筛选。
- 增加零结果提示和清除全部筛选按钮，结果数为读屏可通知区域。
- 分页改用按钮，标明当前页、禁用不可用操作；翻页定位到图鉴内容。
- 原典检字与经篇筛选同步到网址，保留此前兼容的 `search` 参数入口。
- 离开列表时在当前浏览会话保存网址与位置；详情返回链接保留此前筛选，返回后恢复位置。存储不可用时页面仍可正常浏览。

## 阅读路径与全站辅助

- 16 个异兽详情页增加延伸阅读区域，提供原典、地图、文化入口。有匹配地图记录时定位对应异兽，没有记录时明确提供全图入口；无对应原典条目的显示原典目录，不假造匹配。
- 饕餮使用“辨读相关原典”，不把狍鸮条目表述为饕餮本身的原典。
- 按已有名称匹配，补齐地图中 7 个异兽的详情链接。
- 28 个正式页面接入共用阅读辅助：返回顶部、键盘焦点、图片解码和返回列表处理；已有原典阅读进度条不重复添加，异兽详情补充阅读进度条。
- 返回顶部后焦点移到主标题；图片弹窗打开时隐藏浮动按钮，避免干扰弹窗。
- 补齐缺少的站点图标和主题色。生成详情页的脚本同步维护新样式、入口与元信息。

## 布局与视觉

- 图鉴缩减首屏留白、调整标题比例；侧栏与卡片沿用深青绿和古铜金，突出朱砂选中态。
- 1100px 以下先显示图鉴结果，再显示分类说明；手机分类按钮横向滚动，不再占据多行。
- 手机图鉴首屏加强文字背后的深色遮罩。
- 去掉会延迟显示图鉴标题和卡片的入场动画，确保禁用 JavaScript 也能阅读完整图鉴。
- 详情阅读入口使用同一深青绿色阅读带；正文段落限制行宽，统一触摸控件和键盘可见焦点。
- 沿用此前完成的地图动效、地名标签与暂停控制。
