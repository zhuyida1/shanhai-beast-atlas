# 资料来源使用说明

站内原典摘读的原文、注释与译文，以《山海经》异兽图整理稿为底本；神兽图像、地域与路线说明另参考下列资料：

1. 《山海经》新创插图相关研究文章：确定「奇幻、工笔、写意、传统神话」的视觉方向。
2. 《山海经》地图相关研究：确定舆图页采用「路线探索 + 地域筛选」的交互结构。
3. 《图解山海经》：地图路线、山系、山名与异兽内容的参考。
4. 《山海经》异兽图全：原典摘读条目的原文、注释与译文底本。
5. 古籍与线稿类资料：背景纹理、古籍感边框与装饰的参考。

## 图像说明

站内绘制与合成图均为艺术演绎，不作为考据依据。

原典摘读的十条图版取自《山海经》异兽图整理稿：按页定位、裁去页边、统一压到长边 900px 后置入，图像著作权属原书作者与出版方，仅用于本公益科普站点的展示。

## 释义说明

原典摘读的义疏为本站整理出来的读法，与原文分栏阅读；凡涉及后世说法（如四凶、青龙白虎朱雀玄武、龙王系统）的段落，均在文中注明「后世」，不与原典混读。

## 神兽详情的资料层次

详情页正文与引文说明集中维护于 `data/beast-details.mjs`。九尾狐为原有独立页面，其他 15 页据此生成静态 HTML。

- 凤凰、旋龟、蛊雕引《南山经》，穷奇、天狗、狰、蠃鱼引《西山经》，精卫引《北山经》，化蛇引《中山经》，应龙引《大荒东经》。引文均为条目节选，页面说明具体条目，未添加虚构页码。
- 可对读的凤凰、旋龟、蛊雕、狰、天狗、穷奇、应龙链接到站内原典摘读；饕餮链接到狍鸮条目以辨明后世比附。
- 麒麟引用《礼记·礼运》“麟凤龟龙，谓之四灵”，明确标注不是《山海经》引文。
- 白泽与白泽图、重明鸟与《拾遗记》相关传统、玄武与四象文化，以及饕餮与青铜兽面纹，均采用本站文化概述，未将概述排作古文引语。
- 经文、后世解释和艺术演绎分别说明。例如穷奇的牛形猬毛不等于所有后世有翼虎图像，凤凰浴火重生不见于所引经文，旋龟与玄武也不是同一条目。
- 新详情页继续使用仓库已有的 `images/demo/thumb-*.jpg` 插画；未新增外部图片。形貌、配色、姿态和场景属于艺术演绎。

## 导航游龙金边

按用户指定的沿边流光参考，将导航效果独立为 `css/navigation-flow.css` 与 `js/navigation-flow.js`，供各页面和协作者复用。采用单条细金色 SVG 路径与同色透明渐变，沿导航实际轮廓循环，属于本站界面美术创作，不表示原典能力、天象或知识事实。没有引入外部素材、字体或依赖。

本轮只为现有 10 个带顶部主导航的页面添加组件引用，并提供暂停、减少动态效果及后台停止行为。神兽详情、地图地点与路线资料及其他栏目正文沿用主分支。接入和维护方法见 [导航流光组件](navigation-flow.md)。
