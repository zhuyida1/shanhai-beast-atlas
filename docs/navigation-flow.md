# 导航流光组件

导航游龙金边独立维护在两份文件中，不需要地图脚本、第三方库、图片、字体或构建工具：

- `css/navigation-flow.css`：细金边、流光及暂停按钮样式。
- `js/navigation-flow.js`：边框路径、渐淡拖尾、尺寸适配及暂停逻辑。

## 接入

在页面的 `</head>` 前加入：

```html
<link rel="stylesheet" href="css/navigation-flow.css">
<script src="js/navigation-flow.js" defer></script>
```

脚本自动为 `header nav` 和 `header button[aria-controls]` 添加流光。页面仍由自身脚本管理菜单展开与关闭；组件不创建或复制菜单，不修改链接、当前栏目、文字及正文。没有顶部主导航的神兽详情页和结构图辅助页不接入。

其他位置需要复用时，可显式标记一个容器：

```html
<nav data-nav-flow aria-label="主导航">
  <a href="index.html">入画</a>
  <a href="beasts.html">神兽图鉴</a>
</nav>
```

容器需要正常参与布局并有实际宽高。不要放到 `display: contents` 的容器或原生替换元素上。新增接入页面时将两份引用放在该页面样式之后。

## 效果与使用

采用一条 1.6px、`#c99848` 的金色描边，以透明度渐变形成连续拖尾。尾长最多 140px，小按钮按周长缩短；一周约 5—9 秒，地图桌面导航约 8 秒。细线贴合实际轮廓及四角圆弧，不改变导航原有边框占位和排版。键盘焦点框继续可见，装饰层不接收点击和焦点。

各接入页的页脚提供“暂停导航流光／开启导航流光”。偏好保存在 `shanhai-nav-motion-paused`，跨页面及标签同步；存储不可用时仍可使用本页开关。系统减少动态效果、页面后台或导航移出视口时停止流光。地图原有暂停开关也能停止本页导航流光，地图中的地点、路线动效继续由地图自身管理。

关闭脚本时保留页面原导航；打印时隐藏动画装饰与控制按钮。直接以 `file://` 打开页面可用。若其他代码在页面加载后调整导航尺寸或位置，可调用 `window.ShanhaiNavigationFlow.refresh()`；组件同时监听窗口、字体及容器尺寸变化。

## 协作者获取

合入 `main` 后，在没有未提交修改的本地仓库执行：

```bash
git switch main
git pull --ff-only origin main
```

只需要复用效果时，复制上述两份组件文件，并按“接入”添加引用即可。

## 验证

Windows Edge / Playwright 已检查 27 个根目录页面在 1400px 和 390px 下的显示，以及 10 个接入页面在 768px 下的显示，共 64 组。接入页面的 30 组页头／导航坐标、尺寸和链接逐项对照主分支基线，均一致；10 页 HTML 只增加两条组件引用，其他 17 页保持原样。

已实际检查连续流动及渐变方向、7 组既有手机／平板菜单、暂停跨页和跨标签保存、系统减少动态效果、后台及视口外停止、浏览器存储不可用、直接本地打开、禁用脚本降级、显式标记复用和重复加载。地图唤醒／常驻涟漪／经文路线、首页画卷、图鉴与原典检索正常，无新增控制台、脚本和资源错误。

主分支神兽图鉴在 768px 下已有页头横向溢出；本轮与修改前一致，没有将紧凑菜单改版混入动效组件。桌面和 390px 手机检查无新增溢出。
