日期：2026-10-19。状态：**P0 内容底表、P1 首轮地图优化已完成并验收；P2 为后续扩展范围。** 原方案编制时仅新增本文件；用户随后授权执行，现已更新两页及其直接依赖。下文保留原方案的规划语境，实际结果见 [内容核查](habitat-content-audit.md#2026-10-19-资料驱动优化实施补记) 与 [追加验收](habitat-map-validation.md#2026-10-19-资料驱动优化追加验收)。

## 1. 推荐方向与本次边界

在现有圆形舆图上增加“山系阅读、经文路段、山水名物”三层内容，将地图从异兽位置索引提升为可以循经阅读的山海画卷。

- 保留首页延续下来的墨绿背景、米色纸面、青绿山水、金线和朱砂交互，以及圆形构图、右侧手札、名录入口。
- 优化范围为 `map.html`、`habitat-detail.html` 及其直接依赖，不启动暂停中的全站重构。
- 保留原有 23 个异兽记录 ID、页面地址、图片和旧地图文件。当前 22 个地点是已有数据基线；新增经文辅助节点必须单独计数。
- 继续使用本地 HTML、CSS、JavaScript、SVG；无需后端、数据库、在线地图服务或构建步骤，直接打开本地页面仍可使用核心功能。
- 地图始终表示神话地理与相对关系。圆形轮廓属于本站视觉创作；不得宣传为复原的先秦原图、真实地貌或现代经纬度地图。

## 4. 地图画面与页面结构

### 4.1 总图：先看山海，后见细节

保留圆形外框与中央、外围山陆的画卷构图。降低规则刻度和重复波纹的存在感，增加海岸转折、岛屿留白与山体前后层次，避免所有地方呈现相同的三角山和树。

- 延用当前页面色值：墨色 `#171c1b`、纸色 `#f3e6ca`、金色 `#dbb879`、朱砂 `#a82320`；山体在现有青绿色系内扩展远近浓淡，不更换整站风格。
- 山体使用长脊、孤峰、重峦、缓坡等不同轮廓，配少量细线皴理；不靠大面积照片或整张扫描书页拼贴。
- 海水更疏朗，纹样对比低于地名与热点；地名以深墨色题签为主，朱砂集中标示可选点和当前选择，金线用于选中和路线。
- 全图只显示重点地名与少量环境提示，普通地点仍可从名录、搜索或点击区域进入。放大后渐进显示更多标签。
- 总图同屏最多安排约 3—5 处小幅异兽线描作为构图点睛；选中地点可显示一幅对应线描。线描属于原创示意，正文插画仍放手札。没有可信对应形象时不强行配图。
- 裸岩、树丛、水纹等装饰不得与已核对条目直接冲突。例如章莪条明确“无草木”，其选中局部不能画成密林。

### 4.2 区域：山系成为阅读单位

保留现有经篇入口，在选中一篇山经后显示第二级山系选择，例如“西山经 → 西次三经”。首批只显示已有记录涉及、并已逐项核对的山系，不生成没有内容的空菜单。

“海荒经”作为本站合并入口继续保留，其下细分记录实际所属的《海外北经》《海内东经》《大荒东经》等；界面说明这是阅读分组。不同篇章的空间体系不能拼接成一条统一的现实方位链。

- 全图层：山海轮廓、重点地点、朱砂热点。
- 山系层：该山系地点、已核对路段、必要的经文辅助节点。
- 地点层：附近有依据的草木、水源、山上／水中关系与异兽选择。

以上为同一页面中的渐进阅读，不增加强制三步流程。点击热点依旧可以直接读手札。局部视图按路段的经文方向布局；若总图中的艺术位置无法同时满足方向，使用局部示意布局，通过同一个地点 ID 联动，不在总图上画出方向相反却标称经文路线的线段。

### 4.3 桌面与手机

- 桌面保留地图约 70%、手札约 30% 的阅读重心；手札顶部呈现异兽与地点，其后依次为环境、经文、来源、详情入口。
- 山系选择紧接经篇选择；环境图层与资料状态放进“更多筛选”。避免主工具栏同时铺开过多按钮。
- 手机继续保留地图与名录双入口；点选后在地图下方显示可展开手札，不用悬浮卡遮住整幅地图。
- 手机山系菜单用下拉选择，路段卡可横向浏览；地图与列表保持同一选择状态。
- 所有点位的实际点击范围至少 44×44 像素；视觉朱砂点仍保持小巧。点位说明必须可点击、可聚焦，不能仅靠鼠标悬停。

## 5. 路线：把经文关系变成可读内容

### 5.1 两种路线分开

现有 `routes` 表示本站主题浏览顺序，不能直接改名为原典路线。新增带逐段出处的“经文路段”，现有浏览顺序保留为可选功能。

- 经文路段：金色细实线、方向箭头、起终点；点击展开原句和版本定位。
- 本站浏览：低对比虚线，明确标注“本站浏览顺序”。
- 叙事关联：空心标记配文字，必要时在手札中列关联地名，不绘制未经文支持的迁徙线。
- 里数保留为经文文字，例如“西南四百里”；不换算公里，不据此生成比例尺，不将线段长度冒称里程。

地图下方增加一条轻量路段卡：“槐江之山 → 昆仑之丘｜西南四百里｜查看经文”。显示该条路段覆盖范围，不能将局部片段称为完整西次三路线。

### 5.2 首批可直接落实的路段

| 路段 | 本轮已复核依据 | 具体实现 |
| --- | --- | --- |
| 槐江之山 → 昆仑之丘 | 《山海经全译》PDF 67—68，书页 37—38；昆仑条前“西南四百里” | 在西次三经局部中按西南方向布置，联动英招、陆吾两条现有记录 |
| 章莪之山 → 阴山 | 同书 PDF 69，书页 39；“又西三百里，曰阴山” | 与上一段分开显示，局部体现阴山在章莪之西；同时读到章莪“无草木”及阴山出水 |
| 招摇之山 → 堂庭之山 → 猿翼之山 → 杻阳之山 | 同书 PDF 31，正文起页；逐段为东三百里、东三百八十里、东三百七十里 | 南山首段试点；堂庭、猿翼作为经文辅助节点，不新增虚构异兽卡 |

不得把昆仑直接连到章莪并暗示相邻。二者之间有其他经文节点；首版保留两段间的断开并注明“此处仅展示已录入片段”。以后扩展须逐个录入中间节点和相邻边。

中次十一经作为下一批扩展：先核对翼望、朝歌等中间节点，再串到丰山。不可因为当前地图只收录翼望、丰山，就把二者直接标成经文相邻山。

### 6.2 手札的固定阅读顺序

1. 地点、异兽名、经篇和山系。
2. 环境关系：例如“邽山·山上／濛水·水中”，并说明是经文记载还是本站整理。
3. 简短白话摘要。
4. 经文摘录及出处，明确所据版本。
5. 可折叠的版本说明、后世解释、艺术演绎；没有对应内容就不显示空块。
6. 地域详情和既有神兽详情入口。

资料状态从一整条“已核对／待核实”，升级为读者能理解的分项说明，例如“经篇已核对｜形态已核对｜住所关系待辨”。不显示没有来源的百分比、风险值或伪精确评分。

穷奇是必要的图文差异案例：当前邽山文字是牛形猬毛，不能用虎形有翼的艺术图替代本条文字。现有插图可继续作为艺术演绎，补明图文形象不同；没有核实插图所属版本时，不猜测画家或年代。

## 8. 执行顺序与每步完成条件

## 9. 验收清单

### 内容

- 保留全部 23 个原记录 ID；明确新增经文节点不计入异兽数量。
- 山系和经篇由原文定位核对，同名阴山、翼望不串联、不误合并。
- 带山不出现异鸟“御火”；形态、名字形和所在篇章的状态分别清楚。
- 应龙的故事地名、原文方位与现代译者解释清楚区分；不显示无依据的确定住所或迁徙线。
- 章莪局部体现“无草木”；邽山的山上／水中区分清楚。
- 原典里数作为引文显示，不做现代比例尺；只对确有相邻依据的节点绘制经文边。
- 每个新增事实具来源及条目定位；PDF 页和书页不混写；扫描不清的字标为待校。

### 交互与布局

- 约 1400px 桌面导航不换行，地图与手札比例合理；390px 手机无页面横向溢出，地图拖动不误触外层页面。
- 检查全图／山系切换、搜索、复合筛选、无结果、同地异兽、放大拖动、手机双指、标签显隐和所有路线模式。
- 点击路段可读逐段原文；不连续片段保持断开；辅助节点有自己的内容呈现，不沿用上一只异兽手札。
- 老链接及 `point`、`chapter`、`category`、`review`、`labels`、`route`、`z`、`cx`、`cy` 状态可继续恢复；新增山系、视图、路段等状态刷新后可恢复，非法值安全回退。
- 旧 `route=1` 保持本站浏览含义，不能被静默改成另一种路线；新增经文路线使用单独状态。
- 从地图进入地域详情再返回，恢复地点、山系、视图与缩放；浏览器前进／后退正常。
- 键盘可完成地点选择、山系选择、路段阅读；聚焦有可见提示，颜色之外还有线型、名称和图例。
- 尊重减少动态效果设置；不增加持续闪烁、自动平移或阻碍阅读的动画。

### 本地与回归

- 本地直接打开及本地预览服务均检查，图片、脚本、样式、内部链接无缺失，控制台无新增错误。
- 核对共享底图与无脚本副本、详情局部图的版本一致性。
- 首页轮播、图鉴搜索筛选和既有导航做必要回归，记录既有问题与本次新增问题的区别。
- 记录桌面和手机优化前后截图，以及关键内容与路线校验结果；沿用现有验证材料，针对新交互补必要检查。
